# Reliable Text-to-SQL Data QA Assistant

## Problem
Companies have too many tables, so SQL generated by LLMs is often inaccurate.
V1 tackles this on a bounded ~5-table slice and measures accuracy with a fixed evaluation set.

## User
Business users who can't write SQL but need answers from the company database.

## V1 scope
- One relational database (PostgreSQL), ~5 understandable tables with explicit PK/FK
- Data: SEC Financial Statement Data Sets, one quarter (2025 Q4), bounded company subset
- Natural-language question → validated read-only SQL → result + the SQL used
- Fixed evaluation set measured before any UI work

## V1 does NOT include
- Multiple databases, microservices, Redis/RabbitMQ, self-hosted GPU inference
- Fine-tuning, multi-agent orchestration, a large frontend
- Any proprietary data: public SEC data only

## Data source
SEC Financial Statement Data Sets — https://www.sec.gov/data-research/sec-markets-data/financial-statement-data-sets
Data is "as filed" and may contain inconsistencies. Raw data is not committed to this repo; see `docs/` for download steps.
